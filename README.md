# Cue

Open-source, macOS-only quick-capture scratchpad for AI-heavy workflows — a
to-do list, clipboard, and prompt stash in one Liquid Glass side sheet.
An alternative to [Copper](https://shadcn.com/copper).

**Status: early development.** See [SPEC.md](SPEC.md) and [TICKETS.md](TICKETS.md).

## Requirements

- macOS 26 (Tahoe) or later

## Building from source

```sh
brew install xcodegen
xcodegen generate
open Cue.xcodeproj
```
